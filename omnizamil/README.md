# Omni-Removal

Desktop app = Omni UI + omnizamil video/image engine.

## Run

```bat
cd omnizamil
npm install
cd engine\gwr_video
npm install
cd ..\..
npm start
```

First launch: click **Install Dependencies** if prompted.

## Engines
- **Video:** `engine/gwr_video/fast_export.mjs`
- **Image:** gwr watermark SDK
